# Chapter Readability Analyzer

A free browser-based tool that analyzes a pasted chapter.

## Features
- Readability score using the Flesch Reading Ease formula
- Word count
- Sentence count
- Five hardest sentences
- Highlights difficult sentences in the chapter preview
- No login and no external API required

## How to run
Open `index.html` in a browser.

## GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to a GitHub repository.
Then go to Settings -> Pages -> Deploy from branch -> main -> /root.
GitHub will provide the live website link.
